Ledger Test Console

Test every endpoint of the Transaction Ledger API. Full API docs: /docs

POST/accounts

Create an account. The balance always starts at 0.

POST/accounts/{id}/transactions

Credit adds money, debit removes it. Reusing a reference_id on the same account is a duplicate.

POST/transfers

Move money between two accounts in one all-or-nothing operation.

GETBalance & history

History is newest first, with an optional type filter and pagination.
